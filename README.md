# CalPoly UserScripts

A collection of userscripts for CalPoly students.
Install these these with [TamperMonkey](https://www.tampermonkey.net/index.php) or other extensions.

## PolyRatings Hyperlink
Hyperlink professor names to PolyRatings when building your schedule.

> **https://github.com/1withspaghetti/CalPoly-UserScripts/raw/refs/heads/main/polyratings_hyperlink.user.js**

*Click the above link to install, or copy the url into "TamperMonkey Extension -> Utilities -> Import from URL"*
